Command line tool

Print-ready zine generator

Turns a collection of plain-text articles into a LaTeX-built PDF, imposed for saddle-stitch printing so the pages land in the right order once the stack is folded.

Source on GitHubPython 3 and a LaTeX toolchain

The part that is easy to get wrong

Typesetting eight pages is straightforward. Printing them so they read correctly after folding is not. On a saddle-stitched booklet the first sheet carries the last page beside the first, the second carries the second-to-last beside the second, and so on inward. Get the arithmetic wrong and every copy is waste paper, which you discover after printing.

Building the example collection

$ python3 zinegen.py examples/field-notes.json --out build
built /tmp/tmpfgwrup_4/zine-saddle.pdf

The imposition it worked out

Eight content pages become four printed sides. Sheet 1 front carries page 8 on the left and page 1 on the right, which is what makes the cover come out as the cover.

$ cat build/manifest.json  # summarised
title            Small Signals
mode             saddle
paper            letter  11.0 x 8.5 in
content pages    8
output pages     4

  sheet 1 front  left page  8   right page  1
  sheet 1 back   left page  2   right page  7
  sheet 2 front  left page  6   right page  3
  sheet 2 back   left page  4   right page  5

The manifest is emitted alongside the PDF so the imposition can be checked without opening a viewer, which is also how the test suite verifies it. Download the built PDF.
